# Portfólio Pessoal — Lucas Eduardo

## Sobre o Projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar minha história, meus interesses, meus conhecimentos e meus projetos na área de tecnologia.

O site foi desenvolvido como projeto final do 4º bimestre do curso de Desenvolvimento de Sistemas da ETEC, com o objetivo de aplicar na prática os conhecimentos adquiridos durante os estudos.

A identidade visual segue uma proposta moderna, com tema escuro, cores neon e elementos interativos, buscando proporcionar uma experiência agradável aos visitantes.

## Acesso ao Projeto

- **Site publicado:** [Acessar Portfólio] https://lucassouzaportfolio.vercel.app
- **Repositório no GitHub:** [Visualizar Código] https://github.com/LucasEduardo55

## Tecnologias Utilizadas

- **HTML5:** utilizado para estruturar o conteúdo das páginas.
- **CSS3:** responsável pela estilização, identidade visual, layouts e efeitos visuais.
- **Bootstrap 5.3.8:** utilizado para auxiliar na construção do layout, dos componentes da interface e dar responsividade ao site.
- **JavaScript:** utilizado para implementar funcionalidades e interatividade no site, principalmente o botão Modo Claro/Escuro.

## Funcionalidades

- Página inicial com apresentação pessoal.
- Página Sobre Mim, com informações sobre minha história, meus interesses e meus aprendizados.
- Identidade visual com tema claro (cores mais padrão) e escuro (cores neon).
- Alternância entre os temas visuais.
- Efeitos de interação em elementos da interface.
- Layout organizado para facilitar a navegação.
- Utilização de recursos do Bootstrap para auxiliar na construção das páginas.
